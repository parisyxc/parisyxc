### 另外四个工具，分别怎样用

- **Audience Lens Selector｜先选研究视角**：从这次营销决策出发，判断按需求、决策心态、场合或其他变量看人，哪一种最有帮助。把假设变成后续研究可以检验的问题。[Skill](https://github.com/parisyxc/audience-lens-selector/blob/main/SKILL.md) · [示例文件](https://github.com/parisyxc/audience-lens-selector/tree/main/demo)
- **Cultural Brand Analyzer｜读懂文化意义**：研究品牌回应了什么文化矛盾，如何借助神话、符号和仪式形成意义。重点是文化解读。[Skill](https://github.com/parisyxc/cultural-brand-analyzer/blob/main/SKILL.md) · [使用指南](https://github.com/parisyxc/cultural-brand-analyzer/blob/main/USAGE.md) · [示例文件](https://github.com/parisyxc/cultural-brand-analyzer/tree/main/demo)
- **Product Video Studio｜从能力走到脚本**：提供产品、这条视频主打的一个能力、平台与时长。依次发展场景、冲突和脚本，确认后再进入分镜。产出服务拍摄或生成，视频渲染需另行完成。[Skill](https://github.com/parisyxc/product-video-studio/blob/main/SKILL.md) · [示例文件](https://github.com/parisyxc/product-video-studio/tree/main/demo)
- **GEO Content Planner｜积累可回答问题的内容**：提供品牌、用户所处情境和平台分工，从查询到答案模块，再到月度分发，让内容逐渐形成 AI 搜索可引用的证据。是否被引用和推荐，需要继续跟踪。[Skill](https://github.com/parisyxc/geo-content-planner/blob/main/SKILL.md) · [示例文件](https://github.com/parisyxc/geo-content-planner/tree/main/demo)

这些工具可以独立使用，交接时提供对应的 brief 和材料。各仓库说明了怎样加载 skill、参考文件和模板；HTML demo 下载后可在浏览器打开。

## 当前实践 Shopify research and learning Brain

### [Brand Research Brain 从一个感兴趣的网站开始 →](https://github.com/parisyxc/brand-research-brain)

选品时，我常遇到的问题是：看过很多优秀品牌，灵感散落在收藏、笔记和不同对话里，难以继续比较和推敲。我希望它们能够积累下来，成为随时可以回去讨论的材料。

Brand Research Brain 把这件事变成一个可以持续进行的流程：

**贴一个网站 → 读懂这个生意 → 学到三个具体做法 → 保存关联知识与 HTML → 继续 brainstorm 自己的产品想法。**

官网、文章和 clip 都可以作为输入。每次学习从四个维度积累：

- **品牌**：谁买什么，为什么会考虑它，定位如何落实到产品和页面。
- **品类**：先讲清本案属于什么品类，再理解它的创新切口与产品取舍。
- **用户增长**：按需研究社交媒体、创作者与 SEO，拆解具体内容和有依据的增长阶段。
- **灵感借鉴**：从当前案例提炼自己的假设，联系旧笔记，讨论下一步怎样验证。

相关的 Shopify 产品页、建站与转化做法也会按材料沉淀。它借鉴 Karpathy 的 LLM Wiki 思路：原始资料留在 `raw/`，关联知识积累在 `wiki/`，用 Markdown 和 Obsidian 持续维护。研究还会生成一份中文 HTML，方便阅读和截图分享。

### 安装 Brand Research Brain

首版推荐在 **Codex 或 Claude Code** 中使用。完整流程需要本地文件读写、Python 3.9+，以及宿主提供的网页读取能力。基础研究无需额外连接付费数据 API，仍会使用现有 Agent 与搜索额度。

**Codex 在电脑终端执行：**

```sh
codex plugin marketplace add https://github.com/parisyxc/brand-research-brain.git
codex plugin add brand-research-brain@brand-research-brain
```

**Claude Code 在电脑终端执行：**

```sh
claude plugin marketplace add parisyxc/brand-research-brain
claude plugin install brand-research-brain@brand-research-brain
```

按客户端提示刷新或开启新会话，然后给它一个自己的文件夹和网站：

> 使用 Brand Research Brain，在我指定的文件夹创建一个中文 Shopify 学习 Brain。我正在探索适合个人创业的品类，希望学习选品、定位和内容。先研究这个网站：[URL]。讲清它的生意和品类亮点，提炼三个具体做法，沉淀当前案例自己的 ideas，并生成中文 HTML。

之后继续使用同一个 Brain：

> 结合我已经研究的案例，和我 brainstorm 这个想法：[你的想法]。请比较具体做法、适用条件和取舍，给我一个可以尝试的小验证。
